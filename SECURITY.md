# Security Policy

## Supported Versions

Only the latest production release is supported for security fixes.

| Version | Supported |
| ------- | --------- |
| Latest production release | ✅ |
| All previous releases | ❌ |

Because this project does not backport security fixes, please reproduce issues on the latest production release before reporting.

## Reporting a Vulnerability

For repository **libplctag/libplctag**, please report vulnerabilities privately using GitHub's **Private vulnerability reporting** feature:

- Go to the **Security** tab in this repository.
- Click **Report a vulnerability**.

If needed, you may also contact the maintainer directly at: **kyle.hayes@gmail.com**

Please include as much detail as possible:

- Affected version/commit
- Reproduction steps and/or proof of concept
- Impact and potential severity
- Any suggested remediation

## Response Expectations

- Initial acknowledgment: within **five business days**
- Follow-up updates: as investigation progresses
- Remediation timeline: depends on severity and complexity

## Disclosure Policy

Please do **not** open public issues for suspected vulnerabilities.

This project follows coordinated disclosure. A public advisory and fix details will be shared after validation and remediation, when appropriate.
